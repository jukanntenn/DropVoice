# DropVoice 0.0.2 版本发布计划

## 背景

最近两次提交修复了一个重要 bug（文本输入不完整问题），准备发布 0.0.2 版本。

### 最近提交摘要

| 提交        | 描述                                                                            |
| --------- | ----------------------------------------------------------------------------- |
| `e737a01` | feat: add buffered text input with configurable delay to fix incomplete input |
| `f856df3` | feat(input): add configurable input delay to fix incomplete text injection    |

### 新增功能

1. **字符逐个输入模式** - 解决 Windows 平台文本输入不完整的问题
2. **可配置输入延迟** - 用户可在设置中调整字符间延迟（1-100ms，默认10ms）
3. **新增 UI 组件** - Slider 和 Label 组件
4. **多语言更新** - 中英文设置界面新增输入延迟配置项
