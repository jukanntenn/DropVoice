**合并时的关键修正**（详见 spec 11 各节"决策理由/修正说明"）：
- 优先级修正：自动发现 > 扫码 > 手动（原 spec 11 v1.0.0 写的是信令优先）。
- 局域网发现：以 spec 11 实现说明为准（移动端走 HTTP `/discover`，UDP 广播仅原生预留）。
- 409 Conflict：删除（重复注册是预期行为，幂等 upsert 用 201/200）。
- device_id：客户端生成 UUID v4（非服务端生成）。
- device_name：固化默认值，取消 hostname→IP 运行时回退。
- 广播格式：4 字段（含 version/name，不含 device_id），固定 2 秒间隔。
- 压缩：axum 不压缩，Caddy `encode gzip`。
- 技术栈：版本更新至 2026-07 最新正式 release。
- 监控告警：L1+L2+L3 必须，L4+L5 标记后续。
- 部署：回源端口 8443，axum localhost:38424，TLS 用 Cloudflare Origin 证书，PWA 走 Pages。
