# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1] - 2026-02-24

### Added

- **Cross-platform support**: Windows, macOS, and Linux
- **LAN text transmission**: Send text from mobile browser to PC via WebSocket
- **Multi-language interface**: English and Chinese (desktop & mobile)
- **Theme system**: Light, dark, and system-following modes
- **System integration**: System tray, auto-start on boot, minimize to tray
- **Mobile experience**: QR code connection, PWA support, mobile settings page
