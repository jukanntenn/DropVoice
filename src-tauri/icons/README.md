# DropVoice Icons

This directory should contain application icons in various sizes:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)

For development, placeholder icons will be generated by Tauri CLI.
For production, replace these with actual application icons.

A simple icon design for DropVoice could be:
- A speech bubble with a drop/wave symbol
- Colors: Purple gradient matching the app theme (#667eea to #764ba2)
- Minimal, modern design
