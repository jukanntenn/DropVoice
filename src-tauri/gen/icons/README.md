# Generated Icons Directory

This directory is auto-generated by the Tauri CLI during build.
Do not manually edit files in this directory.

To customize application icons:
1. Place your icon files in src-tauri/icons/
2. Supported formats: .png (various sizes), .ico (Windows), .icns (macOS)
3. Run `npm run tauri build` to regenerate app bundles

Icon requirements:
- Windows: icon.ico (256x256)
- macOS: icon.icns (1024x1024)
- Linux: icon.png (512x512)
